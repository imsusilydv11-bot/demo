# LF Loom & Form

A polished, zero-build 3D-inspired textile e-commerce storefront designed for GitHub Pages.

## Included
- Responsive editorial storefront
- Interactive draggable textile orb
- Product filtering by material
- Shopping bag with localStorage persistence
- Demo checkout interaction
- No build step or framework required

## GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Before launch
Replace demo products and brand details in `app.js` and connect a real payment provider. Checkout is currently a demo.
